Название проекта: Random Quote Generator

Описание

Random Quote Generator — это GUI‑приложение для генерации случайных цитат. Программа позволяет:

просматривать случайные цитаты из предустановленного списка;

фильтровать цитаты по автору и теме;

отслеживать историю сгенерированных цитат;

сохранять историю в JSON‑файл и загружать её при следующем запуске;

добавлять новые цитаты с проверкой корректности ввода.

Приложение разработано с использованием Python и библиотеки Tkinter для графического интерфейса. Данные хранятся в формате JSON, что обеспечивает простоту сохранения и загрузки истории.
